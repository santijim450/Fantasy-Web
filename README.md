# Salón de Fiestas Fantasy - Web App

Página web moderna para el Salón de Fiestas Fantasy, reconstruida con React y Vite, presentando un diseño premium (Vanilla CSS) y visualización 3D interactiva de las instalaciones.

## Características
- Diseño responsivo y animado con efecto Glassmorfismo.
- Explorador interactivo 3D embebido.
- Rutas rápidas con React Router.
